# NCT · 砖了个划

NCT 主题拖动配对小游戏。使用 HTML、CSS 和 JavaScript，图片随项目打包，无需构建。

## 玩法

- 每局随机 10 位成员，默认 112 块挑战关。
- 拖动时显示移动路径；只消除手指控制的一对。
- 未成功匹配时整串方块回弹。
- 点击同款头像晃动，消除时头像碎裂。

## 本地运行

在项目目录运行 `python3 -m http.server 8000`，然后打开 `http://localhost:8000`。

## GitHub Pages

在仓库 Settings → Pages 中，选择 Deploy from a branch，分支 main，目录 /(root)。
